# ☁️ 休息一下吧

> 一个用 AI 20 分钟做出来的治愈系休息提醒小工具。

打开它，选一个时间，然后什么都不用做。

时间到了，它会温柔地提醒你：

> "站起来走走吧，窗外的光还很好看。"

## ✨ 功能

- 🕐 可选 5 / 10 / 25 / 45 分钟倒计时
- 🎨 暖日落色调，看着就放松
- ☁️ 呼吸节奏动画 + 飘动的云朵
- 💬 计时结束后随机弹出一条治愈提醒（共 6 条）
- ⭐ 星星飘起的庆祝动画
- 📱 手机和电脑都能用

## 🌿 关于这个项目

我是一个 C++ 内核工程师，白天写几万行的底层代码。

有一天加班到很晚，突然想：如果我做一个"只提醒你休息"的东西，不用记待办、不用追踪效率，就是温柔地告诉你——"你该休息了"，会怎么样？

于是我打开 AI，用自然语言描述了我想要什么，20 分钟后，这个页面就出来了。

没有配置环境，没有学新框架，没有 debug 三小时。

就是跟 AI 聊天，然后得到一个让我自己都觉得很治愈的东西。

我把这个发给了几个加班到很晚的朋友，他们说看了好几遍。

**技术不值钱，但能让一个人觉得"被看见了"，这件事很值钱。**

## 🛠️ 怎么做的

- 工具：AI 对话生成（Cursor / ChatGPT / Claude 均可）
- 技术栈：纯 HTML + CSS + JavaScript，零依赖
- 耗时：约 20 分钟
- 部署：GitHub Pages（免费）
