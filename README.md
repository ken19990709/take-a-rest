# 休息一下吧

> 用 AI 20 分钟做的一个休息提醒页面。

打开它，选一个时间，然后什么都不用做。时间到了它会提醒你：

> "站起来走走吧，窗外的光还很好看。"

## 功能

- 可选 5 / 10 / 25 / 45 分钟倒计时
- 暖日落色调的界面，看着就放松
- 有云朵飘过，有呼吸节奏的动画
- 计时结束后随机弹出一条提醒（目前有 6 条）
- 手机和电脑都能用

## 起因

我是一个 C++ 内核工程师，白天写底层代码。

有天加班到很晚，突然想：做一个只提醒人休息的东西，不记待办，不追踪效率，就说一句"你该休息了"，会怎样？

于是我打开 AI，描述了一下我想要的效果，20 分钟后这个页面就出来了。没有配环境，没有学框架，没有 debug 半天。就是跟 AI 聊了几轮，得到了一个我自己看着都挺舒服的东西。

发给几个经常加班的朋友，他们说翻来覆去看好几遍。

## 技术细节

- 纯 HTML + CSS + JavaScript，没有依赖
- 部署在 GitHub Pages 上
- 用 Cursor 生成（ChatGPT 和 Claude 也能做到类似效果）
